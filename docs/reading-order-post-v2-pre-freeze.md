# Reading Order post-v2 pre-freeze provenance

This note records provenance for the **calibration-only** C1/C2/C3 candidate in PR #163 before any new held-out corpus is authored. It is not qualification evidence and does not claim generalization from H01-H16.

H01-H16 are observed calibration/regression fixtures only. Numeric values classified as calibration-derived below are allowed candidate constants, but they must be frozen before the next held-out is authored and must not be retuned after reveal under the same experiment identity.

## Provenance categories

- **A — algorithmically derived / structurally motivated:** the value follows from a specific implementation property. If that property changes, the value must be re-derived before a future experiment is frozen.
- **B — direct production reuse, same semantics:** the value/rule is reused for the same geometric meaning as production.
- **C — related production reuse, new semantic context:** production contains the same or a related value/rule, but the post-v2 candidate applies it to a different quantity or object. Production history is not independent justification for the new use.
- **D — calibration-derived frozen candidate constant:** selected while investigating the already-observed H01-H16 calibration fixtures; no independent derivation is claimed.

## Non-numeric frozen semantics

- C1 only changes whether a boundary-coupled center containment is confidence-bearing; rejected assignment remains uncertain.
- C2 keeps uncertain nodes as uncertain nodes. It may add only geometry-derived precedence relations; it does not assign those nodes to panels. One-sided evidence, non-unique slots, relation conflict, or graph cycles fail closed rather than fabricating a slot/order.
- C3 is eligible only from original `fewer-than-two-groups` segmentation with exactly one merged group. Acceptance requires exactly one strong complete anchor, exactly one uniquely occlusion-supported companion, sufficient visible evidence, deduplication, and successful unchanged production `_validate_boxes` topology validation. Rejection returns the exact original fallback path.
- B1 is the frozen v2 `_b1_local_order` implementation reused unchanged.

## Freeze rule

This document records provenance; it does not authorize qualification. Before a new held-out corpus is authored, the candidate source identity and all category A-D values/rules above must be frozen under the next experiment specification. After held-out reveal, changing any of them invalidates that experiment identity rather than permitting replay/tuning on the revealed corpus.
